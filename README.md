# Naukri.com — Resume Library & Smart Apply (PM Case Study)

An interactive 11-slide digital product presentation and clickable UX prototype exploring how **Naukri.com** can solve application-time resume switching friction and post-application resume blindness for multi-role job seekers—without disrupting B2B recruiter search on **Resdex**.

## Problem Summary
Job seekers applying across different role tracks (e.g., Product Management, Consulting, Analytics) maintain multiple tailored resumes. In the standard Naukri.com application flow:
1. **Application-Time Friction:** Clicking *Apply* submits the single resume stored on the main profile without prompting for CV selection, forcing candidates into a 5-step detour (leave job → open profile → overwrite resume → return to search → re-find the listing).
2. **Post-Application Blindness:** Candidates have no application-wise record showing which CV version was submitted to each employer once interviews begin.

## What's Inside the Interactive Presentation (`index.html`)
- **Problem-First Framing:** Clear separation of the real-world user problem from the proposed solution.
- **Primary User Research:** Survey findings from 100+ Indian college students (90% maintain multiple CVs, 80% apply across 3+ role categories, 90% frequently need an alternative CV) paired with an honest PM caveat on self-reported data.
- **Competitive Benchmark:** Analysis of LinkedIn Easy Apply, Indeed India, and the distinction between Naukri FastForward and standard Naukri Apply.
- **Live Clickable Prototype (Slide 7):**
  - Pick from saved CVs in-flow during *Apply* without leaving the job feed.
  - Upload a fresh/new CV on the spot with a dynamic checkbox asking whether to save it to the main Resume Library or use it as a one-time submission.
  - Manage up to 5 role-tagged resumes with a dedicated **Resdex Default** toggle.
  - View immutable per-application CV snapshots in the **Applied Jobs** tracker.
- **Architecture, Phased Rollout & A/B Experiment Plan:** Marketplace guardrails for Resdex, 3-phase delivery roadmap, and North Star + guardrail metrics.
