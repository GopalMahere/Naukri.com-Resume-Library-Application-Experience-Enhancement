# Primary User Research & Competitive Benchmarks

## 1. Research Approach
To test whether the resume-switching problem extended beyond personal experience, research was conducted across three pillars:
1. **User Research:** Direct survey outreach to **100+ college students in India** on job application habits, role diversity, and multi-CV friction.
2. **Competitor Research:** Analysis of how LinkedIn, Indeed India, and Naukri's own services handle multiple resumes.
3. **Problem Investigation:** Step-by-step audit of the current application flow.

## 2. Primary Survey Results (n = 100+ College Students in India)

| Survey Metric | Result |
| :--- | :---: |
| Respondents who had recently applied for jobs | **90%** |
| Respondents applying for 4 or more role types | **60%** |
| Respondents applying for 3 role types | **20%** |
| Respondents applying across **3+ role categories** (combined) | **80%** |
| Respondents maintaining multiple resume versions | **90%** |
| Respondents frequently needing an alternative CV while applying | **90%** |
| Respondents rating the proposed multi-resume feature "extremely useful" | **90%** |
| Respondents "very likely" to use the proposed feature | **90%** |

### Honest PM Caveat & Research Limitations
This survey captures **self-reported experiences and interest** from 100+ college students in India. It strongly justifies investigating the problem further, but it does **not** prove that all Naukri.com cohorts (such as senior single-track specialists) experience the same friction or will automatically adopt the feature. Live behavioral validation via an A/B experiment is therefore required before full rollout.

## 3. Competitive Benchmark Summary

| Platform | Saved Resumes | In-Flow Apply Behavior | Key Learning |
| :--- | :--- | :--- | :--- |
| **LinkedIn Easy Apply** | Up to 4 recent CVs | Select saved CV or upload new inside Easy Apply | Proves multi-CV selection during application is practical and familiar. |
| **Indeed India** | 1 file in profile (replacing overwrites old file) | Can select profile CV or upload a different file during Apply | Proves instant in-flow upload reduces the need to exit the application. |
| **Naukri FastForward / Existing Services** | FastForward docs mention up to 5 profiles (1 CV each); online maker documents 1 resume | Separate service, not integrated into standard Naukri Apply | Important not to conflate separate paid/profile services with a clean, integrated Apply picker. |

## 4. Collective Research Takeaways
1. **Validated user need worth investigating** across multi-role job seekers.
2. **Proven practicality** — LinkedIn validates multi-CV selection, while Indeed validates instant in-flow upload.
3. **Clear Naukri opportunity** — combining multi-CV library storage, instant fresh upload with optional save-to-library, and immutable application-wise CV tracking in one unified flow.
